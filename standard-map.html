Conventions

The displayed two-parameter map is

\[ y' = y + \frac{K}{2\pi}\sin(2\pi x) + \varepsilon\sin(10\pi x), \qquad x' = x + y' \pmod 1, \]

with generating function

\[ S_{K,\varepsilon}(x,X) = \frac12(X-x)^2 - \frac{K}{4\pi^2}\cos(2\pi x) - \frac{\varepsilon}{10\pi}\cos(10\pi x). \]

At \(K=\varepsilon=0\), the reference curve is \(\beta_0(\omega)=\tfrac12\omega^2\).
