Conventions

The displayed map is y' = y + K/(2π) sin(2πx), x' = x + y' mod 1, generated by SK(x, X) = ½(X - x)2 - K/(4π2) cos(2πx). At K = 0 the reference curve is β0(ω) = ½ω2.
